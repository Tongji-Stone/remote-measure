# E104 共轴初始化与稳健精修

同一条路线用于棱锥、人偶、南瓜和圆柱。盘上已知码提供每站刚体位姿与共轴初始化 R02。正常流程尝试 Tukey 多尺度 ICP 和修正坐标后的门控位姿图 R06c。满足整圈方位、独立码、深度、重叠和贴底门槛时采用精修，否则保留 R02。

- `robust.py` 实现共轴标定、缺码角插值、Tukey ICP、边门控与联合优化。
- `stitch_manifest.py` 读取另一次扫描的前景点云、同期光学模型与盘面观测。
- `stress.py` 在两套标定分支和五组实测上复跑干净、角站减半、噪声加离群、遮码和虚假环边。
- 每组 `指标.csv` 和 `鲁棒性.json` 含候选、选择折和独立测试折，`推荐.ply` 为 E103 实测点的刚体融合。

## 坐标与验收

物点在相机坐标中以 mm 表示。板位姿 \(A_i\) 从棋盘坐标到第 i 站的相机坐标。绕单位轴 \(u\)、轴心 \(c\)、角度 \(\theta\) 的平移项为 \(c-R_u(\theta)c\)。基线点云位姿为 \(A_0 A_i^{-1}\)，共轴时等效于零位相对角的反向转动。

点对法向阈值 30°，互近邻小于 3 mm，至少 15 对，双向训练支持至少 12%。邻边相对物理先验的改动限 8°、9 mm。邻边误差定义在目标相机坐标，所以轴心先用目标姿态的逆变换表达。旧实现的正向变换在合成对照给出虚假的位移，数值见 `坐标与输入核验.json`。

以第 0 站为锚，优化归一化点对残差和位姿先验。旋转向量各分量限 1.4/65 rad，轴心处平移各分量限 1.4 mm。优化采用 soft-L1，尺度 0.5。留出图块的选择与最终测试分离，留出码组也分开。

精修相对 R02 的门槛为方向缺口增量 ≤2.5°、码 P50 增量 ≤1 px、F1@2 和深度支持率降幅分别 ≤1.5 和 ≤2.5 个百分点、深度 P50 改善大于 3%、贴底垂向漂移 P95 ≤1.5 mm。建议至少四站保有可用码，角站间最大码缺口小于 190°。选择时码或几何样本不足会保留物理位姿。重叠、光学质量和足够角覆盖为适用条件。

## 新扫描入口

```sh
OMP_NUM_THREADS=1 algorithm/.venv/bin/python algorithm/scene-fusion/E104/stitch_manifest.py scan.json output_dir
```

`scan.json` 的 `calibration` 指向 E101 同格式光学 JSON，`angles` 是按一圈内实际采集顺序排列的数组。每项含 `angle_deg`、`cloud` 及可选的 `markers`。相对路径以清单的位置为基准。点云 NPZ 含 N×3 相机坐标 `xyz`、N×2 像素 `uv`、N 个白场灰度 `gray`、图像高宽 `shape` 和可选盘面相对高度 `height`。码文件使用 E101 的 `ids`、`u`、`xyz`，每码四角。输出包含推荐 PLY、刚体矩阵和诊断。E104 使用 E102/E103 筛出的前景开展测试。
