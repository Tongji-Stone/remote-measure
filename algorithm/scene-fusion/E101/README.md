# E101 多视角点云拼接

- **ChArUco** 使用 04:08:39 的 10×10 格 ChArUco 标定序列。
- **Chessboard** 使用 04:25:34 的旧棋盘标定序列。
- 两支路各读取同一套五组、54 个相机视角。两支路的角站标记均来自扫描白场图上的 ChArUco 板，各用所属支路相机参数解 PnP。

每个物品目录包括：

| 文件 | 内容 |
|---|---|
| `单视角/Vxx.ply` | 原相机坐标系，全画幅有效点，灰度颜色 |
| `整圈/Rxx.ply` | 各个方法的整圈点云。刚体变换到 V00，相机图像灰度保留在 RGB，附加 `view_id` |
| `整圈/推荐.ply` | 与结果 JSON 中推荐编号对应的完整 PLY |
| `双视角/` | 推荐方法的 V00、V01 两站合并 PLY |
| `预览.jpg` | 双视角、全景斜视和全景俯视，按角站着色 |
| `结果.json`、`指标.csv` | 位姿矩阵、各邻边指标、回退记录、全量与奇偶减半对照 |
| `采集.json` | 帧号、指令与拟合角、顶点数和灰码位置信度 |

根目录的 `E101索引.csv` 汇总推荐方法与点数，`E101光学验证.json` 保存共同留出码附近的点到 PnP 盘面距离，`E101核验.json` 记录通过核验的组。纯点云交付在 `algorithm/point cloud/E101`，可运行 `export_ply.py` 刷新。

## 点云与评分

解码遍历整个相机画面，以 3 px 网格取样。通过灰码对比度、双设备前方、深度范围 50–1600 mm 和重投影筛选的点全部进入 PLY。扫描板、转台和有效背景均保留。背景若相对相机静止，整圈中会出现重影。体素化、局部去噪与板上方物体区域用于求解或评分。

物体评分固定两套标定都保留的相同像素。24 px 图块分块留出，第 1、5、9 等 ID 的标记角排除在求姿之外。方位覆盖描述角站分布，深度支持来自留出目标帧的 8 px 投影栅格。串联粗配准失败的邻边使用 R02 初值，逐边 JSON 保存状态。末站与首站是独立相邻边，可在全边求解成功时合成闭环；采集没有另拍 360° 返回零位。

## 复跑

从仓库根目录用 `algorithm/.venv/bin/python` 依次运行 E101 目录的 `acquire.py`、`calibrate.py`、`geometry.py` 和 `audit_optics.py`。前四脚本读取原始 PNG，临时缓存写入 `/tmp/E101/cache`。再分别对 `ChArUco` 与 `Chessboard`，运行 `benchmark.py BRANCH SCAN_ID`。本批 SCAN_ID 为 043648、044244、045127、050019 与 050554。

R16、R17、R18 分别需要 `--go-icp <可执行文件>`、`--cloudcompare <可执行文件>` 与 `--teaser <可执行文件>`。实测使用 Go-ICP 提交 `937f114590f7df8b003d05f594b55527e230fef0`、CloudCompare 2.13.2，以及 TEASER++ 提交 `52a9c52ee7d4c838c5e8a75458c33178be5bfb70` 的串行构建。TEASER++ 入口是 `teaser_runner.cpp`，输入六列三维对应用空格分隔，固定尺度、2 mm 噪声界，使用 GNC-TLS。应用同采样的 Open3D ICP 进行精配准。Go-ICP 每邻边搜索最多 3 秒。FlexScan3D 未执行，保留为上一报告的文献方案。

可用同环境的 `report.py`（需要 NumPy、Pillow、ReportLab 和本机 Arial Unicode 字体）重新生成 PDF、指标索引和预览。报告生成会先核查全部 PLY 文件长度、各站点数和刚体坐标抽样。
