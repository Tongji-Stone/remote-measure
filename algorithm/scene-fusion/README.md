# 全场景拼接复跑

[全景 PLY](results/clouds) · [全场预览](results/figures/full_scenes.png) · [位姿俯视对照](results/figures/pose_comparison.png) · [旧纸盒四条接缝](results/figures/paper_box_edges.png) · [Benchmark CSV](results/benchmark.csv)

八组扫描导出 **59 个单视角、8 个全场景**。全景保留参与融合的全部有效三角化点，包括转盘、物体和视野中其它被照到的部分。三次 360° 实拍重复在单视角目录内，作为独立回零复核。

## 为什么小黄人好拼，纸盒难拼

小黄人有八个约 45° 视角，眼镜、手臂与身体之间有能区分方向的几何变化。用同一批小黄人数据和相同位姿，每隔一个角度取一帧，邻边 F1@2 mm* 从 **41.7% 降到 7.3%**。居中纸盒也有同样的趋势，八帧 **13.5%**，四帧 **1.1%**。苹果近似回转体，且只有四个名义 90° 视角。11/16 纸盒也只有四个名义 90° 视角，两个相邻侧壁可能只在一条边上相接。纸盒的重复平面会诱导 ICP 把多个方向的面贴到一起。

A、C 是正式标准件的形状分类。练习件数据还受扫描间隔、投影有效率、遮挡和转轴精度影响。正式 C 类规定平底、连续上表面和无垂向内倾遮挡。赛题最终按体积相对误差加权评分，见队伍提供规则第 10、12 页。

## 建议保留的组合

1. 停转采整幅白场和 44 张格雷图。每 4 像素采样，白黑差 ≥15，正反图有效位差 ≥5。优先全位，必要时最多舍掉每轴最低两位。对 17:41 之后测试横向 Gray 最高位的两种候选，按重投影与深度范围选可用值。
2. 按采集时间选择光学模型。ArUco 组从标记拟合盘面、转轴、轴心和每帧角。旧组从同期档案、盘面、盘缘和可见条带起步。
3. 几何边只有双向 5 mm* 支持至少 15% 才参与微调。现代组调角限 ±1.5°，旧组限 ±3°。训练码残差过大时保留标记轨迹。长方体另走四面模型。
4. 用每个时刻的位姿将所有有效整幅场景点转换到第 0 帧。每组 single/ 保存单帧，full_scene.ply 保存推荐整圈结果。archive_prior_scene.ply 和 unconstrained_icp_scene.ply 用完全相同的点比较位姿影响。背景有效点也随场景保留。三角化质量、遮挡和反光决定实际有效范围。

矩阵与每帧点数见各组 poses_and_metrics.json。mm* 表示同期档案标定尺度。全景已逐点核对是各唯一视角的刚体变换拼合。独立预测放在 [simulation](../../simulation)。

## 评分怎么读

- **位姿优先** 看完整方位、留出 ArUco 像素、回零或旧组条带。最大环形缺口按变换后相机方位计算，它和实际表面照明覆盖是两个量。
- **局部贴合** 用留出像素的双向邻边 F1@2、最差边、互为最近点的法向接缝 P95。薄片或直角侧壁另看边界间距。点密度和可见重叠取决于物体与拍摄条件，各物体的绝对 F1 需要各自解读。
- **留出** 配准与几何评测按 24 px 图块划分，现代标记留一个 ID，模型路线用训练码判断。白场 SIFT 的三维对应由相机与盘面位姿三角化，用来验证投影校正。内部用物体区域评估，整幅场景 PLY 保持原点。[Open3D ICP 指标](https://www.open3d.org/docs/latest/tutorial/pipelines/icp_registration.html) · [OpenCV 标定与 PnP](https://docs.opencv.org/4.13.0/d9/d0c/group__calib3d.html)

11/23 的 44 张图约 11.9 秒/角度，八角度约 95 秒。优先采八个 45° 邻角，再补高视角和回零复扫。换高度后给相机和投影仪单独标定并关联到同一转台坐标。当前诊断用了手标区域，正式采集须用自动轮廓或自动标记与几何分类。
