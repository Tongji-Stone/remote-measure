## Benchmark 执行协议

1. **去盘**。每组两张白场图人工描轮廓，轮廓附近留缓冲，以实际有深度的像素作为评价样本。报告轮廓内解深度率、17:50 等低支撑视角、16 帧平均前景 F1、近盘带（−4 到 +8 mm*）实测前景召回。[标注](labels.json) · [逐帧混淆计数](results/E002-01.csv) · [解码与盘面诊断](results/E002-03.csv)
2. **配准**。每帧的 24 px 图块分训练和留出。按环的邻接边报告 1/2/4 mm* 双向 F1 中位、最差边、2 mm* 内点 RMSE、接缝法向 P95、双向最近邻 P95 和均值。双向近邻含实际互不可见面，宜同 F1、法向接缝与射线结果看。
3. **重投影**。逐帧用剩余视角训练点预测该帧的深度，在 8×8 px 栅格取最近可见点。汇报支持率、绝对误差 P50、前方冲突率（超过 3 mm*）、后方点比例、同时有支持且误差小于等于 3 mm* 的比例。
4. **标定与整圈**。最大方位缺口用各帧位姿的相机位置求得；独立邻边齐全时才计算闭环残差。现代四组从优化中预留 ArUco ID，报告重投影 P50 和对转轴估计的留一角 P95。早期三组另有实拍 0°/360° 重复。无可用标记或缺边在 CSV 中留空。
5. **选用**。去盘在七组上选型、评价被留出的第八组。M07 的 24 mm* 偏心门限在分析本批数据后确定。位姿在 R01、R06–R08 里选用，约束最大缺口增加量 ≤4°、留出码 P50 增加量 ≤1.5 px、投影支持减少量 ≤4 个百分点，再比深度和盒面。本批是开发验证。S06 仍用 R01，S07 的 R06 留出深度 P50 降 46%，方位缺口从 48.5° 增至 52.3°，留出标记误差稳定。S08 的 R08 是深度与标记间的折中。
6. **补全**。实测与估计分别输出，对有参考真值的人工遮挡区单独评分。 [补全协议](../../../simulation/E002/README.md)

## 复跑

在仓库根目录用已有 `algorithm/.venv/bin/python` 执行 `algorithm/scene-fusion/E002/experiment.py`。建议保留 E001 的 `results/intermediate` 缓存并设置 `OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 OPENCV_OPENCL_RUNTIME=disabled`。随后用已有 Matplotlib 环境执行 `algorithm/scene-fusion/E002/plot_numbered.py`。 [运行记录](results/E002.log)

串联 ICP 用于对照。苹果 R10 在深度 P50 上从 3.26 降到 1.29 mm*，最大方位缺口却从 90° 扩到 259°。17:45 纸盒 R10 留出深度约 1.5 mm*，独立 ArUco 偏差约 139 px。这两条数据说明判分需要兼顾配准误差、覆盖与标定。
