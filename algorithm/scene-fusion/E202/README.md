# E202 · 双相机彩色拼接，只保留物体

E202 使用 E201 的刚体位姿和测点颜色。10 组共保留 **1,923,308** 个物体实测点，其中 **80.8%** 取自彩照，**55,038** 个点位于各自盘面的 −0.85…5 mm 内。照片颜色按拍摄时的光照保留，同一个物体在不同摆位间可能有色差。

## 去板与底部

逐站用棋盘实测点拟合盘面，再结合白场物体轮廓、附近连续物体点与跨站支持判定接触区域。确认落在板面码内的点全部剔除。近底实测点计入逐组指标。唱片复合体的深色底座灰码响应弱，扫到的底边为零散片段。

每站仅有一张彩色照片。对这些照片另做跨站三视图三角化与留出核验，通过的轨迹都落在现有表面支持带中，本轮彩照用于已实测点的着色。另行摆位的结构光扫描有独立的实测几何。人偶背部、面部摆位通过留出对齐门槛，在相对正视角盘面 −2.2…8 mm 的范围内合入 **10,020** 个实测点，其中 **7,313** 个与主扫描最近点相距超过 2 mm。每个新增点与主扫描至少相距 1.25 mm，同时要求在补扫本身有邻域支持。南瓜的翻面解有多个接近的方向，棱锥的跨摆位留出边缘偏差较大，两者保留各摆位的独立整圈文件。

## 指标

留出 F1@2 mm 是相邻站双向 2 mm 内点比例的调和平均。法向接缝 P95 反映重叠表面沿法向的偏差。标签重投影 P95 检查位姿与独立码点的一致性。最大角间隔描述角站的环形分布，本轮为 36.77°–37.68°。彩照上色率是采用彩色相机像素的点比例。近底点可能包含不同视角对同一位置的重复采样。
