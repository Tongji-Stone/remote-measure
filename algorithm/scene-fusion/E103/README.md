# E103 去棋盘格并保留可见底部

E103 从 E102 的实测点中选择物体。四种分割方法和它们的白场抽查结果保存在本目录的 `分割验证.csv`。

| 编号 | 分割方法 | ChArUco 近底保留率 | Chessboard 近底保留率 |
|---|---|---:|---:|
| M01 | 板内固定 3 mm 高度裁剪 | 57.1% | 48.8% |
| M02 | 稳健盘面残差、三维连通及白场像素邻接 | 91.6% | 92.7% |
| M03 | M02 加白场轮廓与近邻支持的贴底恢复 | 92.9% | 93.7% |
| M04 | M03 加多角站的贴底旁证 | 92.9% | 93.7% |

近底保留率在五组各三张独立白场轮廓上计算。分母为轮廓内、距板 −0.85 至 5 mm 的原始有效点，轮廓不确定边缘留空。M04 的多角站旁证只添加邻近已测物体表面的点。整圈 ChArUco 保留 48,163 个近板实测点，其中人偶 4,089 个。抽查轮廓 F1 中位约 99.5%，贴底点保留率单独报告。

## 配准对比

两轮沿用 E101 的 19 个编号，另加入 R20，共 20 路。R07 用棱锥侧面，只在两种棱锥姿态求解。R20 固定转轴，用相邻和隔一站的互近邻及对称点到面残差优化，每站只允许有界偏角，同时锚定训练标记。R20 达到的整圈约束稳定，本批未达到替换推荐方案的改善门槛。FlexScan3D 仍为文献方案。

对 E102 和 E103 使用相同的物体像素和训练／留出划分。指标包括双向 F1、最差邻边、接缝 P95、留出深度、方位缺口、留出码重投影和可计算的邻边闭环。新增贴底垂向漂移 P95，以 R02 为参照，推荐候选上限为 1.5 mm。去板只改变输入点子集，每站以刚体位姿拼接。

| 物品 | ChArUco | Chessboard |
|---|---|---|
| 三棱锥 · 小面坐地 | R06 | R03 |
| 三棱锥 · 大面坐地 | R02 | R02 |
| 坐着人偶 | R06 | R02 |
| 小南瓜 | R06 | R02 |
| 维生素包装圆柱 | R02 | R02 |

ChArUco 推荐方案的五组 F1@2 中位为 71.8%，留出深度误差中位为 0.61 mm，贴底垂向漂移 P95 的组间最大值为 0.21 mm。Chessboard 对应为 42.5%、1.65 mm 和 0.95 mm。
