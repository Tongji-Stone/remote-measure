# E003 多视角拼接

[E003 报告](E003.pdf) · [编号索引与矩阵](results/E003-05.json) · [白色网格和补全](../../../simulation/E003/README.md)

8 组、59 个原始角度。使用 E001 按采集时间配对的相机和转台档案、Gray code 三角化缓存、E002 去盘掩膜和位姿。每个候选共享相同的 24 px 留出图块。0°/360° 的 3 帧单独导出，其余 56 帧进入融合。所有配准输出保持刚体变换。

## 按论文拆开的流程

1. **数据、光学标定和去盘**。用同期相机、投影和轴参数恢复单角度深度点。E003 沿用已验证的三角化缓存，读取原照片，保留标定提供的旋转关系。
2. **去噪和法向**。D00 保留 E002 的去盘掩膜。D01 对各视角做 16 邻域的统计离群过滤。D02 用相对密度过滤和跨视角体素连通性，保留邻近主体的较小成分。D03 对照第 4.2 节，用 1.8 mm* 体素和 RANSAC 从原始盘环求盘面，从 D00 剔除拟合盘附近点，再做统计过滤。
3. **同一摆放下的粗、精配准**。R01 是 E002 选出的标定位姿，R02 是同期物理轴。R03–R05 分别将 D00、D01、D02 用于三个尺度的 Tukey 点到面 ICP，再按相邻边支持率、法向和偏离标定的幅度筛选及联立求姿。
4. **无初值的粗配准试验**。论文第 3.5 节用于人工翻转实物之后的多姿态模型。E003 在真实相邻视角上验证 ISS、FPFH 和 SAC-IA 式采样生成粗位姿，再进入同一套 ICP。E003 使用几何比例检验和截断双向近邻评分。R06 仅接纳通过物理门控的特征边。54 对真实相邻视角中 47 对有粗配准候选，12 对通过门控。
5. **PPF 对照与纸盒试验**。按第 4.3–4.5 节用 OpenCV PPF 检测器投票和聚类，再用同一 ICP。每组测一对真实邻角和一个已知刚体位姿的控制。真实组报告相对标定位姿的差，ADD 只用于有真值的控制。纸盒 R07 试共享轴心平移与有限角度，训练码参与拟合，判定用留出码。17:47 组通过，留出深度 P50 由 3.436 降至 3.226 mm*，邻边 F1@2 mm* 从 21.7% 升至 26.0%，独立码从 10.19 降至 9.99 px。
6. **白色表面**。将单视角法向统一朝向相机后做 screened Poisson。M01 按点密度、离实测点距离和支撑成分修剪。补全和规则化在 simulation/E003 中另做。
