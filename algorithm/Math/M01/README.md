# M01 · 用体积检验标定、拼接和重建

本轮用最新五组采集、三种带遮挡的合成扫描和球／椭球／环体的偏差注入测试。**当前实物主流程保留 ChArUco + E104 门控位姿 + E104 形状候选。** 面积加权补偿 D4 是可见曲面偏差的对照。专用截面积模型值得在底形已确认的规则平滑物体上继续试，实物南瓜仍保留 S07。

[Benchmark 与评估规则](benchmark.md) · [文献与公式依据](literature.md) · [V001 求积实验](../../../computing%20volume/V001/README.md)

## 1. 标定和拼接如何影响体积

从同一批露板像素拟合相机中平面的逆深度，两支路用相同的留出码像素定位名义弦长。在 53 个可用站中，ChArUco 的按站尺度偏差中位为 x **+0.37%**、y **−0.34%**、斜向 **+0.05%**，旧 Chessboard 分别为 **−7.20%**、**−7.56%**、**−7.19%**。两轴统计只取该方向可组成至少 15 mm 弦长的站。参考是印刷图纸的名义尺寸，独立实物量具还需验证绝对尺度。

同一 S04 重建核下，旧棋盘支路的体积相对 ChArUco 在五组中 **大 +1.4% 至 +105.2%**。如只把尺度统一缩小 7.2%，体积理论上应缩小约 20.1%。实际变化方向相反，提示裁剪、接触面、视线包络与光学畸变共同决定结果。两次标定原始采样条件也不同。[露板尺度数据](results/calibration_plane_scale.csv) · [同核标定对照](results/calibration_pair.csv)

### H1 · 锚定李代数同步

设 $P_i$ 将第 $i$ 站转到 E102 世界系，$E_{ij}$ 将相机 $i$ 转到相机 $j$。初值已由转轴给出。短边残差
$\xi_{ij}=\log(P_j E_{ij}P_i^{-1})$
统一在世界系。令 $x_i$ 为节点左增量的切向量，有 $x_i-x_j\simeq\xi_{ij}$。固定 $x_0=0$，迭代求解
$(B^\top W B+\lambda I)x=B^\top W\xi$，
用 $\exp(x_i)P_i$ 回到刚体群。计算时转角用 40 mm 力臂换算，矩阵对数与指数都含平移的左雅可比。附带的已知位姿试验检测坐标符号与有限角度近似，干净边恢复的节点位置最差约 **0.003 mm**，加入一条有偏边时约 **0.483 mm**。

同一批点、同一 E102 盘面、同一 S04 核固定，改用 R02、R06c 或 H1。表中 P95 依次列 R02 / R06c / H1。H1 的体积变化相对 R02。

| 采集 | 独立物体点 P95 (mm) | 留出码 P50，R02 → H1 (px) | H1 体积变化 |
| --- | ---: | ---: | ---: |
| P1 小面棱锥 | 1.098 / 1.021 / 0.981 | 1.73 → 7.88 | +3.82% |
| P2 大面棱锥 | 1.073 / 1.039 / 0.962 | 1.93 → 3.97 | +2.92% |
| F1 坐姿人偶 | 0.862 / 0.796 / 0.757 | 1.99 → 5.80 | +5.94% |
| K1 小南瓜 | 1.000 / 0.976 / 0.913 | 1.90 → 5.61 | +6.83% |
| C1 包装圆柱 | 1.037 / 1.037 / 0.891 | 2.07 → 3.92 | +1.70% |

H1 在五组中都压低了配准边和物体表面误差，同时使码误差变大。P2 的近底漂移 P95 达到 **0.69 mm**。同棱锥换摆位的相对差在 H1 下约 8.96%，R02 为 9.83%。码约束的变坏比这点体积一致性收益更明确，当前保留 E104 既有门控位姿。[图与数值](results/figures/M01-poses.pdf) · [位姿、重建网格与原始指标](results/)

## 2. 用形状导数找出有方向的偏差

对一段法向位移 $h(x)$，一阶体积改变量是 $\int_{\partial\Omega}h\,dS$。面积大的一侧持续向外偏 0.3 mm，体积可以明显偏大，即便无符号点面误差仍很小。对每个有向三角形，从 $a\cdot(b\times c)/6$ 求梯度，累加到共享顶点。可用梯度估算候选改变量，再对真实移动后的网格做精确三角积分。V001 中球面 0.50、0.25、0.125、0.0625 mm 位移的线性余项每次约缩到四分之一，符合二阶量级。

- **D0** 保留原网格。**D1** 在测量支持区域用一个鲁棒有符号偏移。**D2** 用三角面重心权重和网格图拉普拉斯拟合局部偏移。先按近邻和视线角去掉可疑对应，锐面间降低导通，E102 盘面及 1.5 mm 内固定。每个点移动限 0.6 mm。
- **D3** 从候选中选最符合留出表面的模型。**D4** 用独立选择折的面积加权有符号残差积分选型，同时用 P95、早交比例、封闭和位移约束门控。用第三折核对效果，另存选用的网格。
- **受控注入。** 六组可见偏差的绝对体积误差中位由 **3.50%** 降到 D3 **0.59%**、D4 **0.14%**。环体全局偏差 **+7.54% → −0.13%**。三个偏差完全藏在底部的试验，D4 全都保留基线，剩余误差 **1.33%–4.44%**。
- **仿真扫描。** G1–G3 的九个 T0/T1/T2 组合中，绝对误差中位 **3.65% → 3.54%**。G3 的 T1 中，D4 后仍约 **48%**，说明数据已支持的点面校正对不可见区域的影响有限。[偏差注入图](results/figures/M01-bias.pdf) · [扫描对照数据](results/synthetic_scans.csv)

| --- | ---: | ---: | ---: |
| P1 | 137.91 | 136.77 | −1.051 → −0.079 |
| P2 | 151.75 | 150.62 | −1.160 → −0.294 |

F1 的 D1/D2 未过几何与拓扑检查，保留细网格 E104。表中残差是留出点覆盖范围的有向面积积分，实物目前无独立参考体积。小面和大面棱锥补偿后仍差约 **9.64%**，未知底形问题没有由补偿解决。统一尺度增加 0.25% 对所有体积约为 **+0.752%**。P1/P2 理想盘面上移 0.5 mm 的一阶影响分别约 **−2.01 / −3.13 mL**。[五组逐候选及回退](results/real_bias.csv) · [扰动灵敏度](results/volume_sensitivity.csv)

## 3. 截面积直接进入重建

星形水平截面由半径 $r(z,\theta)$ 表示。以高度 Chebyshev 基和角向 Fourier 基拟合 $r^2$，再按
$A(z)=\tfrac12\int_0^{2\pi}r^2(z,\theta)\,d\theta$、
$V=\int A(z)\,dz$
积分。R-pole 的端点因子为 $4s(1-s)$，R-flat 的因子为 $1-s$，其中 $s=z/z_{top}$。顶部高度从训练点估计。两者在同一训练点拟合，同一留出点检查。

| G3 试验 | S04 体积误差 | S07 体积误差 | R-flat 体积误差 | R-pole 体积误差 |
| --- | ---: | ---: | ---: | ---: |
| T0 测量覆盖 | +20.14% | +10.96% | +2.17% | +0.12% |
| T1 底带遮挡 | +48.33% | +19.45% | +12.30% | +1.05% |
| T2 侧向遮挡 | +21.03% | +11.25% | +1.22% | −0.01% |

G3 的构造确实满足圆钝、点接触的先验。T1 中两个截面模型的留出 P95 只差约 **0.011 mm**，体积偏差却差 **11.26 个百分点**。实物 K1 的两种模型约 **23.15 / 23.93 mL**，留出 P95 **2.12 / 2.15 mm**，而 S07 约 **0.95 mm**。实物果柄和过渡区偏离统一的截面假设，因此保留 S07，用这两种模型度量形状先验敏感性。[截面积图](results/figures/M01-sections.pdf) · [截面与网格核验](results/sections.csv)

## 4. 复跑和量值验证

从仓库根目录运行。几何脚本使用现有 Open3D Python。标定长度核验读取 E101/E102 的解码缓存。各 PLY 沿用 E102 世界坐标。

```sh
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1
algorithm/.venv/bin/python algorithm/Math/M01/calibration.py
for sample in P1 P2 F1 K1 C1; do
  algorithm/.venv/bin/python algorithm/Math/M01/run_pose.py "$sample"
done
algorithm/.venv/bin/python algorithm/Math/M01/run_bias.py
algorithm/.venv/bin/python algorithm/Math/M01/section_fit.py
algorithm/.venv/bin/python 'computing volume/V001/run.py'
~/.local/share/codex-science/physics-venv/bin/python algorithm/Math/M01/figures.py
```

现阶段优先测长基准件的三轴尺度和同件卸下重放，再对棱锥原接触面补扫并做独立排水。体积数据回填后可用绝对偏差检验 D4 和截面积模型的选型，以复测估计尺度、位姿与补全不确定度。

早期日志以 `pilot_` 开头。正式偏差结果以 `*_v2.log` 对应，含 D4。早期实物灵敏度曾尝试把盘面单独上移和让邻接带同步形变视作相同操作，K1 对照发现两者不同。正式表分别记录平面单独位移和 0–2 mm 邻接带渐变形变的导数。
