# 转台物体数据采集

双击 `采集物体数据.bat`。关闭其他相机软件，确保投影仪作为扩展屏幕连接。

1. 命令窗口询问每次计划转动的角度，例如 `90`；若反方向转动可输入 `-90`。不知道时直接按回车。
2. 将物体放稳，点击相机预览窗口，按空格采集第一组。此时不能转动转台。
3. 终端出现 `Capture complete` 后，通过 ESP32 网页转动转台；等转台停稳，再按空格采集下一组。重复操作。
4. 完成后在相机预览窗口按 Q 退出。

结果保存在 `data/object_scans/scan_时间/`，每一组保存在独立的 `view_0000`、`view_0001` 等文件夹，里面有 44 张图片；`session.json` 记录各组采集状态、曝光、增益和计划角度。角度是按输入的步长和组数推算的**名义值**，不是传感器测量值。仅当每组之间都恰好手动转动一次相同角度、没有漏步或打滑时，记录才对应实际操作；不确定时留空。

以上手动采集方式不会控制 ESP32 和转台；采集后可在操作台运行重建和拼接。手动旋转时保持相机和投影仪位置、对焦不变，确保投影和相机都覆盖物体。每张图切换后先等待 100 毫秒投影稳定余量，再等待一段相机曝光时间，清空缓存、丢弃一帧后才保存下一帧。此为保守的软件时序，尚需针对实际投影仪验证。对称或遮挡多的物体可以用较小角度（例如 15°～30°）取得更多重叠；90° 能快速测试，但相邻图像可能缺少重叠，不一定适合拼接。

每个采集完成的视角会生成 `timing.json`，记录总时间、每帧的投影等待、相机取帧、图像转换、预览和保存等待时间。后台编码和写盘与采集并行，它们的耗时之和不能直接加到总时间上。终端也会打印简要统计。

## 自动旋转采集

1. 连接相机和投影仪，退出其他相机程序；连接 ESP32 所在网络，在 ESP32 页面确认电机空闲、白灯关闭，物体放稳。
2. 双击 `自动旋转采集.bat`，输入 ESP32 网页地址，例如 `http://192.168.4.1`（以实际地址为准）。程序会先读取状态，不会在启动时立即转动。
3. 在操作台设置不含回环的采集组数；默认 8 组，即约 0°、45°……315°。程序按每圈 4096 半步计算每步转动并取整，步进间隔 3 ms；控制器报告停止后等待设定的稳定时间，默认 1 秒。在预览窗口按空格开始。最后一组采完不再转动。
4. 转动或稳定等待期间在预览窗口按 Q 可请求停止；状态异常或通信失败也会中止，并尝试发送停止命令。若断线，停止指令可能无法送达，应检查电机实际状态。采集期间不要从网页或其他程序同时控制转台。

要增加一张约 360° 回环视角，可在操作台勾选“额外采集 360° 回环”，或在命令行加 `--loop`。照片仍按 `data/object_scans/scan_时间/view_0000` 等目录保存，`session.json` 记录控制参数、每个视角和转动状态；45° 为根据 512 半步约定的名义值，不是实测角度。控制器报告步数完成不能排除电机失步或物体打滑。网络异常时不自动重发移动指令，避免重复转动。

自动采集沿用完整的 44 张图案及上述曝光相关等待时序；最细条纹的可靠性仍需另外验证。采集结束后，可在操作台的“转台拼接”页进行重建。


## 图形操作台

双击 `打开扫描操作台.bat`。先退出其他占用相机的程序，并将投影仪设为扩展屏幕。

在“采集”页，左侧设置参数和操作按钮，右侧显示相机实时画面。点击“启动实时预览”连接相机，再次点击同一个按钮停止；修改曝光、增益或自动曝光选项后，重新启动预览即可应用。当前默认曝光为 50000 微秒，可按亮度修改。

标定和手动物体采集：点击相应的“开始”按钮，摆稳标定板或物体后点击“采集当前视角”；等待本组完成，再调整姿态采下一组。再次点击同一个采集按钮停止。自动旋转采集点击开始后自动采集各视角，再次点击可请求停止。停止发生在一组采集中途时，不完整的照片会保留并标记中断，不能用于重建。采集期间右侧显示相机画面，投影仪另行全屏显示格雷码；启动采集会先释放普通预览的相机。

自动转台仅在控制器确认空闲后工作；停止时程序会尝试发送停止命令，网络中断时仍需检查转台实际状态。手动调焦画面显示在操作台右侧，投影仪单独显示白光或条纹。

### 曝光与手动调焦

在“采集”页输入曝光时间（微秒）和增益（dB）；也可勾选“自动曝光一次后锁定”。程序调用相机自身的一次自动曝光，临时将其自动曝光时间上限调整为 200000 微秒，完成后锁定曝光并恢复相机原来的上限；界面曝光框显示相机返回的实际值。普通预览按当时的照明测光，不会自动点亮投影仪；标定、物体采集和调焦会先投白光再测光。不同背景、反光及物体面积会影响测光，需检查主体亮度和白色区域是否过曝；如不合适，取消自动曝光并手动设置。曝光变长会改变画面亮度和信噪比，也可能让运动模糊变大，不会自动改变镜头焦点。

若希望只按物体区域决定曝光：先启动实时预览或手动调焦，分别在相机画面选择测光框，再点击“按框选区自动曝光”。预览模式左键框选曝光区域；调焦模式左键框选调焦及曝光共用区域，右键仅调整曝光区域。蓝色虚线框显示测光范围。程序根据框内亮部和过曝比例逐步调整曝光，完成后将曝光值填回界面并取消整幅画面的自动曝光选项，后续采集按此值锁定。ROI 只用于测光，不裁剪采集图像。

框选测光默认为保护亮部；如果主体偏暗，可以把“框选测光补偿 EV”设为 +0.3 或 +0.5 后重新测光。+0.3 EV 对连续曝光约增加 23%，+1 EV 约增加一倍；FHD C3 使用离散曝光档，实际补偿会四舍五入到可用档，日志会显示实际值。测光完成后检查日志中的过亮比例，光亮处饱和会损失格雷码信息；该补偿只对“按框选区自动曝光”生效，不改变相机内置的整幅自动曝光。建议用白光框住有代表性的物体表面，避免选入过多背景或镜面高光，并检查图案采集效果。

点击“开始手动调焦”，先在转盘工作高度放一张有清晰纹理的平整纸或标记，直接在右侧画面用鼠标拖框选择要检查的区域，程序会将选区自动放大；点击“返回全图重新选框”可退回全图，也可以在放大的画面内继续框选更小的区域。放大仅改变显示，照片仍按原分辨率采集。白光画面下缓慢转动相机镜头：声音越高表示相对当前已见最佳值越清晰，来回比较最高音附近；点击“重置最高分”可开始新一轮比较。极暗、过曝、均匀或强反光的区域不适合判断清晰度。

点击“切换白光 / 横竖条纹”，保持相机镜头不动，再缓慢调投影仪焦距，分别检查竖条纹和横条纹。分数和声音都是相对提示，不代表绝对合焦；还要看条纹边缘是否清楚、是否有周期性明暗。再次点击“停止手动调焦”退出。完成后锁定焦距，采集标定图和物体时不要改动相机、投影仪位置或焦距。

### 标定与自动拼接

点击“采集标定图像”后，每次启动会新建 `data/procam_calibration/calibration_时间/`，本次每组照片分别保存为其中的 `capture_时间/` 子文件夹，避免同名照片覆盖。每组仍包含 44 张图案照片。移动并倾斜棋盘格采集多组，棋盘内角点保持清晰、完整且位于相机与投影仪共同覆盖范围内。

在“转台拼接”选择整个物体扫描文件夹，并选择上一步的标定会话文件夹，或选择已经计算好的标定 XML。若选标定会话文件夹，程序自动寻找其中的 XML；没有 XML 时从其中的棋盘照片求解。若文件夹里有多个 XML，应直接指定要使用的那个。设置实际棋盘格边长、内角点数，以及转盘上 ArUco 标记黑色方框的实际边长；界面默认值只是默认参数，须与实物一致。

选择自动标记拼接后，程序从各视角白光照片识别转盘上固定的 ArUco 标记，依据相同编号估计各视角之间的位置关系，并重建、拼接点云，无需另选转轴文件。每个视角至少要与首个视角共同看见两个清晰标记，标记要牢固且不能被遮挡；扫描时物体与标记都不能相对转盘移动。该方式依靠标记直接估计相对位姿，并非自动完成转轴几何标定。结果保存在扫描文件夹新建的 `aruco_reconstruction_时间/` 中，`merged_aruco_experimental.ply` 为合并点云，`registration.json` 为配准记录；点云包含可重建出的转盘和背景，可在“查看与绘图”打开。

日志出现质量警告时，仍可能生成点云，但不代表拼接或尺寸准确；应检查标记实际尺寸、相机与投影仪是否沿用同一套标定、标记遮挡、重投影误差和点云重影。小物体、反光、条纹解码失败也会造成缺点。忽略最细格雷码位数可按数据情况调整，点数更多不等于精度更高。

操作台保留原来的转轴 JSON 拼接方式及旧数据专用试验。转台步数、名义角度和标记拼接均不能代替独立精度验证。


### 2026-11-24 相机速度实测

当前 MV-CA050-12UM、2448×2048、每帧约 5.01 MB，关闭相机的帧率限制，连续取流在曝光 100～100000 微秒时均约 7.48 帧/秒，测试中帧号没有跳号；曝光 150000 微秒时约 6.65 帧/秒。逐次发送软件触发并等待收到图像，在 50000 微秒曝光下约 6.52 帧/秒。以上是当前相机、电脑和连接方式下的实测，不等于更换接口或调整分辨率之后的极限。

旧版结构光采集每投一张图会清空缓冲、丢弃一帧并保存下一帧；该旧版在 50000 微秒曝光下采集 44 张实测约 11.88 秒。新版增加投影稳定余量和曝光等待，因此会更慢，具体耗时以新数据的 timing.json 为准。软件触发可能减少等待，但需要验证投影切换、实际曝光和图案的一一对应，不能把软件触发帧率直接作为可靠结构光采集速度。

裁剪传感器的实测对照如下。裁剪会缩小实际视野，并非普通图片缩放；要用于结构光，须重新确认相机与投影仪共同视野、采样细节及重新标定，不能直接沿用全画幅标定。测试后宽高、偏移、曝光与帧率限制已恢复。

| 相机采集区域 | 曝光 | 连续采集实测 |
|---|---:|---:|
| 2448×2048（完整画幅） | 50000 微秒 | 7.48 帧/秒 |
| 1224×1024（裁剪） | 50000 微秒 | 19.80 帧/秒 |
| 1224×1024（裁剪） | 100 微秒 | 29.93 帧/秒 |
| 640×480（裁剪） | 100 微秒 | 121.95 帧/秒 |
| 32×32（最小裁剪） | 15 微秒 | 1524.37 帧/秒 |

32×32 仅用于测试极小区域的读出速度，无法代表完整物体的扫描速度。


### 检查投影和相机时序

当前无投影仪光学反馈或硬件同步信号，软件等待并不能证明实际光输出已经稳定。建议用一块固定的浅色漫反射板，将相机曝光设为 100000 微秒，运行 `check_projection_sync.py` 的黑白交替测试。日志和 `data/sync_tests` 下的 JSON 比较旧时序与新时序每次黑白交替的测量结果；如果可见混帧，需要进一步增加稳定等待或采用硬件同步。全白、全黑可检查明显的前一帧混入，但不能单独证明所有细条纹和每个像素均同步可靠。
