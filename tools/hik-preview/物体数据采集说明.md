# 转台物体数据采集

双击 `采集物体数据.bat`。关闭其他相机软件，确保投影仪作为扩展屏幕连接。

1. 命令窗口询问每次计划转动的角度，例如 `90`；若反方向转动可输入 `-90`。不知道时直接按回车。
2. 将物体放稳，点击相机预览窗口，按空格采集第一组。此时不能转动转台。
3. 终端出现 `Capture complete` 后，通过 ESP32 网页转动转台；等转台停稳，再按空格采集下一组。重复操作。
4. 完成后在相机预览窗口按 Q 退出。

结果保存在 `data/object_scans/scan_时间/`，每一组保存在独立的 `view_0000`、`view_0001` 等文件夹，里面有 44 张图片；`session.json` 记录各组采集状态、曝光、增益和计划角度。角度是按输入的步长和组数推算的**名义值**，不是传感器测量值。仅当每组之间都恰好手动转动一次相同角度、没有漏步或打滑时，记录才对应实际操作；不确定时留空。

程序不会控制或检测 ESP32 和转台，不会自动重建、标定转轴或选择标定文件。手动旋转时保持相机和投影仪位置、对焦不变，确保投影和相机都覆盖物体。当前图案切换等待为 0.01 秒，其同步可靠性尚未验证。对称或遮挡多的物体可以用较小角度（例如 15°～30°）取得更多重叠；90° 能快速测试，但相邻图像可能缺少重叠，不一定适合拼接。

每个采集完成的视角会生成 `timing.json`，记录总时间、每帧的投影等待、相机取帧、图像转换、预览和保存等待时间。后台编码和写盘与采集并行，它们的耗时之和不能直接加到总时间上。终端也会打印简要统计。
