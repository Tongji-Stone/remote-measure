# E003 局部补全与规则化

| --- | --- |

| C02 | 小黄人照片轮廓引导点 |

## 各物体怎么做

- **小黄人**。头、眼镜、衣身沿用实测曲面。白场 V00/V01 的人工轮廓提供两只脚蹼的近盘面投影，覆盖 V07 留出图可见脚蹼区域的约 75.4%。用 V07 可见轮廓评估 2.2 mm* 高度切片，M03、M05、M06 的 IoU 分别为 51.5%、51.2%、44.6%。展示用 M05，并保留误差相近的 M03。脚底厚度和轮廓背后依赖近盘高度假设。照片辅助分支只在 T0 执行，T1 仅用剩余三维点做局部补全。
- **苹果**。保持有效视角提供的上半部和果梗凹窝。下部从 32 个方位的实测低轮廓延拓，加入候选点后做 Poisson。底部曲率及体积需从另一摆放姿态核验。
- **充电头**。只在可相互对应的对向局部平面约束平行，按与支撑片的距离平滑减弱约束。输入样本移动量上限 2.3 mm*。两组留出局部角差约 5.48° → 0.03°、17.01° → 0.64°。这是补全层的规则度。原点云和 M01 可核对倒角、凹槽和孔口。很浅的细节可能受 1.2 mm* 封闭网格采样分辨率影响。
- **纸盒**。按共享正交轴、对向平行面与共同交线拟合 M04。四组均提供规则化网格和实测 M01。11/16 的角部突出和其他三组的盒面重影分别记录。17:47 的 E003 配准 R07 已独立改善重投影和配准分数。

## 遮挡评价

T0 使用完整实测输入。T1 从所有视角去掉同一空间内较低的一片已测表面，固定配准，重跑建模。文件 C00-T1-reference.ply 是删去的实测参考。CSV 报告已有点到实际三角面的 P50/P95、留出点 2 mm* 召回与 P95、随机表面采样的弱支撑占比，以及通过闭合检查的体积。弱支撑指 2.5 mm* 内无实测建模点。闭合确认拓扑，体积为候选表面的估计。

论文启发包括 [Liepa 的局部补面](https://diglib.eg.org/items/bd5c3658-4de6-4336-a7bd-0baf4f5618ac)、[带包络的 Poisson](https://gfx.cs.princeton.edu/pubs/Kazhdan_2020_PSR/index.php) 和 [GlobFit 的局部平面关系](https://graphics.stanford.edu/~niloy/research/globFit/globFit_sigg11.html)。E003 的射线留空和宽松包络约束施加在输入和重采样阶段。
