# E104 补全、网格和体积

E102 的棋盘格提供盘面高度与含盘对照。E103 的前景点和逐站位姿提供建模输入。两套标定各跑五组实物。三个已知几何用本装置的相机方向模拟采样。各组比较 T0、底带遮挡 T1、侧向遮挡 T2。

| G1/G2/G3 | 已知棱锥、圆柱与沟槽曲面 | 包含参考网格与体积 |

每个场景的 `T0-S01-visible.ply` 是按点距和密度保留的 Poisson 可见面。各 `T1-withheld.ply`、`T2-withheld.ply` 是被遮挡、仅用于评价的实测点。白色三角网格与点云都使用盘面坐标和标定尺度。实物体积是与候选表面对应的外形估计。棋盘格支路的 P1、P2、K1 保留实测面优选，闭合候选未通过共同误差门槛。

闭合重采样体素边长为 1.25 mm。至少两站同意的已测自由空间排除占据。最终闭合模型按实测支撑面在 [零高贴盘封底](贴底重建说明.md)。体积候选按完整 T0 的贴盘底盖、水密性、已测误差差值 ≤0.8 mm、首交前冲比 ≤8% 和盘下表面比例 ≤1.6% 筛选，在合格集合中最大化 T1/T2 召回均值。少数闭合候选有拓扑清理记录，可在各组 JSON 查看。

从项目根目录用 `algorithm/.venv/bin/python simulation/E104/experiment.py P1 ChArUco` 等命令复跑。随后运行 `finalize.py P1-ChArUco` 核对拓扑，运行 `finalize.py index` 刷新索引。合成组用 `experiment.py G1 GT`。运行依赖 Open3D、SciPy、NumPy、OpenCV，本阶段可从已导出的 PLY、各组 E102 露板索引和标定／位姿文件复跑。
