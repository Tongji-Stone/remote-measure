# E104 实测缺面重建与体积检验

| 方向 | 依据与应用 |
|---|---|
| 局部封孔 | Liepa 的边界三角化、细分和平滑适合边界完整的局部孔。实验 S02 采用 Ball Pivoting 建面后限径补孔。 [BPA DOI](https://doi.org/10.1109/2945.817351) · [Open3D 建面](https://www.open3d.org/docs/release/tutorial/geometry/surface_reconstruction.html) |
| 隐式重建 | Screened Poisson 将有向法向组成的向量场与实测位置共同纳入重建。实验 S01 运行 Open3D，并另存支撑裁剪版。 [原文与源码](https://hhoppe.com/proj/screenedpoisson/) |
| 包络、视觉壳和深度壳 | Laurentini 由多视角轮廓交集约束范围。Kazhdan 等把包络作为 Poisson 的 Dirichlet 边界。S04 和 S07 在 Poisson 之后用盘面、保守射线投票和包络限制重采样。 [Visual Hull DOI](https://doi.org/10.1109/34.273735) · [包络 Poisson 原文](https://gfx.cs.princeton.edu/gfx/pubs/Kazhdan_2020_PSR/index.php) |
| 深度融合 | Curless–Levoy 在体素上累积带权距离。S06 用本机标定投影，融合截断距离，在有观测的单元提等值面。 [SIGGRAPH 原文](https://aperture.stanford.edu/papers/volrange/) |
| 形状先验 | GlobFit 在工程件上联合拟合局部几何和全局关系。S05 按实物结构选择棱锥三侧面和盘面、圆柱的轴与轴向半径，或自由形状的局部接触带。S07 延拓南瓜下方随方位变化的轮廓。 [GlobFit 原文](https://graphics.stanford.edu/~niloy/research/globFit/globFit_sigg11.html) |
| 学习式点云补全 | PoinTr、AdaPoinTr 和 PCN 适合探索多解与类别先验。当前五种样本与预训练形状的域差、真实可见底面缺失以及 CUDA 自定义算子影响本机对照，列为文献方案。 [PoinTr 论文](https://openaccess.thecvf.com/content/ICCV2021/papers/Yu_PoinTr_Diverse_Point_Cloud_Completion_With_Geometry-Aware_Transformers_ICCV_2021_paper.pdf) · [作者实现](https://github.com/yuxumin/PoinTr) · [PCN](https://arxiv.org/abs/1808.00671v1) |
| 商业对照 | FlexScan3D 提供局部交互补洞。Geomagic 的网格示例提供平面、曲率等填充操作。商业操作来自厂商资料。 [Polyga](https://www.polyga.com/flexscan3d/) · [Geomagic 示例](https://www.youtube.com/watch?v=2Wgy-pmI_K6) |

T0 使用全部有效角站，保留分块表面样本做独立评分。T1 在坐标系中切去全部角站的同一底带。T2 切去同一 72° 侧向区。切去的深度只用于评分，射线和网格拟合取训练数据。三组已知形状使用真实扫描方向与相机模型作射线采样，比较闭合体积偏差和完整表面 F1。E102 给出盘面以及含板 Poisson 对照，E103 给出物体点与各角站姿态。

统计保留点到三角面 P50/P95、隐藏区 2 mm 召回、参考射线前方冲突和未受实测支持面积占比。闭合体积通过有向、无自交和水密性检查。紧贴盘面的实物接触内侧需要翻面实测、排水或标准尺度件进一步核验。
