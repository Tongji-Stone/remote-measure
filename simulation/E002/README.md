# E002 真实扫描补全

八组点云均来自 [E002 去盘与姿态实验](../../algorithm/scene-fusion/E002/README.md)。橙色表示模型采样点 2.5 mm* 内缺少实测近邻。模型点在盘面坐标系，原点和基向量见各组 JSON。直接比较时用同目录的 C00 点云。

| 方法 | 适用数据 | 结果 |
| --- | --- | --- |
| C01 平底凸包 | 八组 | 八组 T0 都封闭；在小黄人与部分纸盒上会跨越凹陷 |
| C02 平底高度场 | 八组 | 八组 T0 都封闭；保留实测高度变化，假定底面平坦 |
| C03 加轮廓与深度约束的高度场 | 八组 | 八组 T0 都封闭；更适合做一般物体的体积基线 |
| C04 直立长方体 | 四组纸盒 | 四组 T0 都封闭；三组人工遮挡区的 P95 优于高度场，偏心组较差 |
| C05 补盘面法向的 Poisson | 八组 | 八组 T0 网格均未达到闭合检查，体积留空 |
| C06 平面相切椭球 | 苹果 | 人工遮挡召回 54.2%，P95 为 13.61 mm*；外形较规整，局部误差仍大 |

### 两组测试

- **T0 全部实测输入**。用完整去盘点云补全，测闭合性、体积、已有点到模型的 P50/P95。表面距离基于固定数量的模型点采样。
- **T1 遮住一片已测区域**。先在融合坐标定义一片区域，再从所有视角输入中移除该区域的样本。C03 只使用留下的深度作空域约束；C04 重新在剩余点上拟合。用实际移除的点算 2 mm* 召回和 P95。真实底面依赖补扫或标准件才能校核。

结果共 66 项，58 项满足闭合检查。S08 的长方体假设给出 260.1 cm*³，高度场给出 265.5 cm*³。苹果的椭球和高度场分别是 329.0 与 438.9 cm*³。两种数值的差反映形状假设敏感度；mm* 为沿用档案的标定尺度，cm*³ 等于 1,000 mm*³。深度空域依据见 [Curless 与 Levoy 的原论文](https://cs233.stanford.edu/papers/volrange/)。

### 文件

- 每组 `E002-Sxx-C00.ply` 是补全实际使用的盘面坐标点。保留高度 −2.5 到 155 mm* 内的点，并将低于 0.04 mm* 的点贴到该高度。17:47 和 17:50 分别舍去 27 和 24 点。原始去盘坐标保存在配准目录的文件 02。
- `-C00-T1.ply` 是遮挡测试输入，`-C00-T1-reference.ply` 是移出的实测参考。
- `E002-Sxx-Cnn-Tm.ply` 是蓝色实测支撑区域、橙色弱支撑区域组成的模型点；`-mesh.ply` 是三角网格。
