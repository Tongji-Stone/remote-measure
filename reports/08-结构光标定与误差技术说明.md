# 结构光标定与误差技术说明

更新日期：2026-11-15

## 一、系统怎样得到三维位置

投影仪依次投射黑白条纹，相机逐张拍摄。程序通过一个相机像素在整组图片中的亮暗变化，推算照到该位置的是投影仪的哪个像素。建立对应关系后，结合事先计算出的相机和投影仪位置，就能用三角测量计算三维点。

这套程序对 1280 × 720 投影输出使用 42 张格雷码图案和全白、全黑参考图，共 44 张。图案的黑白区域遍布整个投影画面；物体若落在某张图的黑色部分，该图中的物体就会很暗，与之配对的反相图应更亮。

## 二、标定与误差怎么计算

标定程序将棋盘格角点当作位于同一平面、间距已知的点。它先从相机照片找到角点，再由相机拍摄的格雷码图案推算角点对应的投影仪位置。使用多组不同姿态的角点，程序计算相机、投影仪的成像参数和两者之间的位置关系。

求出参数后，程序将棋盘格角点重新投影到相机和投影仪的像素坐标中，比较预测位置与检测或解码位置。两者偏差汇总后得到**重投影误差**；当前程序使用 OpenCV `stereoCalibrate` 返回的联合误差。像素误差不是物体尺寸误差，不能直接换算为毫米误差。误差较小也不能代替用已知尺寸物体进行独立验证。

2026-11-13 从 11 组中选取 6 组数据试算的结果：

| 项目 | 初步误差 |
| --- | ---: |
| 相机单独标定 | 约 1.20 像素 |
| 投影仪单独标定 | 约 7.49 像素 |
| 相机—投影仪联合标定 | 约 5.50 像素 |

这些结果仅供排查，不是最终标定结果。相机与投影仪分辨率不同，像素误差的物理意义不完全相同。投影仪侧误差更大，提示需要重点检查图案、解码和程序，但无法仅凭这三个数字确定故障来源。

原仓库的标定代码存在图像尺寸的宽高顺序问题。试算修正顺序后，联合误差约 5.42 像素，仍较大；该次结果因保存路径问题没有成功保存。当前的 `calibration_result_初步未验证.xml` 是原试算结果，暂不能作为高精度测量参数。

在原始数据中，`capture_20261113_121505` 和 `capture_20261113_121711` 的棋盘角点附近可用解码点很少；`capture_20261113_121824` 没有找到棋盘格。这些现象说明部分照片不适合直接用于当前试算，但不单独证明原因是光圈、失焦还是采集不同步。

## 三、主要误差来源

| 因素 | 会怎样影响结果 | 检查方式 |
| --- | --- | --- |
| 棋盘格不平 | 纸张鼓包或纸板翘曲时，真实角点不在程序假定的平面上。 | 用直尺检查缝隙，观察是否有皱褶、鼓包；纸板易变形时换更平整坚固的底板。 |
| 打印尺度 | 打印缩放或横纵比例不一致会影响点的真实间距；统一尺度偏差可能使三维结果按比例偏大或偏小。 | 用尺测多个方格的总长度，横纵都测；按实际值填写尺寸。不要只看打印设置。 |
| 相机对焦 | 角点模糊，位置不易准确识别。 | 在预期测量距离对焦，检查各姿态的角点边缘；之后固定对焦环。 |
| 投影仪对焦 | 黑白条纹边界模糊，尤其细条纹难以区分。 | 在测量区域投射条纹并对焦，检查工作范围内的清晰度。 |
| 光圈 | 光圈太大景深可能不足；太小会使画面变暗，过小还会因衍射损失清晰度。 | 兼顾标定板各姿态的清晰度与亮度，正式标定前固定光圈。 |
| 曝光与增益 | 过暗、过曝、灯光闪烁或高增益噪声都会让黑白图案难以区分。 | 关闭自动曝光和自动增益，检查全白图和正反图；此前 10 ms 在一次测试中比 5 ms 稳定，仍需结合当前光源重测。 |
| 相机与投影切换时序 | 相机可能拍到上一张图或画面切换过程，导致解码错误。 | 在固定场景下比较 0.01 秒与较长等待设置，逐组检查图案对应关系及解码结果。 |
| 标定板移动、支架变化 | 同一组的 44 张图若位置变化，对应关系会错；相机、投影仪或镜头改变后，旧标定可能不再适用。 | 每组采集时固定棋盘格；固定设备，并在测量前确认未移动、未重新对焦。 |
| 姿态和覆盖范围不足 | 各组过于相似，或只覆盖测量区一部分，会使参数不稳定。 | 在预期测量区域内选不同位置、距离和适度倾角，确保角点和投影都清楚。 |
| 算法和参数 | 角点定位、黑白阈值、坏点、拟合方法和代码尺寸顺序都会改变结果。 | 核查输入分辨率、每组有效点和单组误差；用独立数据验证。 |

目前没有做控制变量实验，不能对这些因素的影响大小作定量排序。实际排查优先关注已有迹象：部分组解码点过少、投影仪侧误差较大、采集等待时间缩短后未做完整同步验证，以及标定代码需要修正。

## 四、建议的验证顺序

1. 检查棋盘格平整度和实际尺寸；固定相机、投影仪、焦点和光圈。
2. 在同一静止场景下，分别以 0.01 秒和 0.2 秒等待采集，比较正反图、可解码像素以及投影坐标；每次只改变等待时间。固定等待只是整个采集间隔的一部分。
3. 修正并复核标定代码，检查每一组的角点数量和误差；补拍清晰、姿态有差异的标定板图片，不靠盲目删组压低误差。
4. 使用未参与标定的平板、已知尺寸物体进行独立检查，分别评价平面形状和尺寸偏差。逐步改进标定后，再进行多角度拼接和体积测试。

## 五、当前物体测试结果

长方体、纸杯和焊锡卷已经生成单视角试验点云。长方体部分侧面可见，但不同面容易错误配准；纸杯侧面、底面、凹面之间重叠不足；焊锡卷反光且有效点较少。当前结果没有可靠地拼成完整模型，不能用来计算物体体积。

### 单视角点云筛选

当前 `reconstruct_object.py` 默认横向、纵向每隔 2 个相机像素取一个样本。程序要求全白图减去全黑图的亮度差大于 40，每对格雷码图的亮度差大于 5；还会排除解码坐标超出投影画面以及落在相机或投影仪背后的点。默认没有自动识别物体并剔除背景，因此背景是否出现取决于照明、解码和遮挡等条件。先前单独生成的区域点云还使用过矩形裁剪。

### 长方体约束拟合试验

前一次固定转轴拼接只让相邻点云的一部分尽量接近，并未要求所有点落在长方体面上，因此可能把不同平面贴错，造成面看起来交叉。屏幕上的投影交叉不一定是三维空间中的真实相交，需要旋转查看。

后续试验使用 `124450`、`124618`、`124643`、`124852`、`124950` 五组点云；第一组 `124327` 因有效点较少未使用。已知条件是按时间顺序同向绕固定轴转动，相邻转角不超过 70°。程序额外假设转轴平行于相机坐标的竖直方向；共同轴的位置、各次角度和长方体横向尺寸由拟合估计，长方体高度由输入点云的高度范围估计。

程序让各组点云尽量靠近假定长方体的四个侧面，并限制尺寸和转角的搜索范围。一次最优候选给出的相邻角度约为 **30°、57°、70°、47°**；其中一次达到 70° 搜索上限。不同初始条件得到不同候选解，说明结果尚不稳定。拟合时对大残差做了截断，输出的残差指标不能视为全部点的真实平均误差，更不能当作尺寸或体积精度。

黑色线框是模型推断；彩色 PLY 只保存变换后的采集点，没有包含线框。物体部分侧面、顶面和底面没有得到充分观测，模型补全不能当作实测。输入还可能含有支撑物，试验使用的相机—投影仪标定也未验证，因此当前拼接和拟合结果均不能用于可靠测量。
